# 示例说明

这个文件夹里的脚本用于演示 `el05.py` 的常见用法。建议每次只运行一个示例，运行前确认官方上位机已关闭、串口号正确、电机 ID 正确、机械限位安全。

推荐顺序：

1. `read_feedback.py`  
   只读取反馈，不使能、不发目标位置。用于检查通信、接线、电机是否有返回。

2. `pp_minimal.py`  
   最小 PP 位置控制：切 PP -> 使能 -> 发目标角度。适合确认库能驱动电机。

3. `pp_with_limits.py`  
   PP 位置控制，并显式设置速度和加速度。比最小 PP 更适合日常调试。

4. `motion_control_basic.py`  
   运控模式基础示例，使用反馈检查和保守的 `Kp/Kd`。确认 PP 稳定后再测试。

5. `head_follow_motion_safe.py`  
   运控模式实时跟随结构示例，包含目标平滑、限速、限加速度、反馈超时和故障检查。适合后续做人脸/目标跟随时参考。

补充：

- `recover_check_no_motion.py`  
  低风险恢复/检查脚本：清故障、读版本、停止。不使能、不发目标。

注意：

- 电流模式、速度模式和 CSP 模式已经在 `el05.py` 中封装，但没有默认提供可直接运行的运动示例，避免误操作。
- 运控模式比 PP 模式风险更高，第一次测试请使用小角度、低 `Kp/Kd`、`torque_nm=0`。
