# 示例说明

这个文件夹里的脚本用于演示 `el05.py` 的常见用法。建议每次只运行一个示例，运行前确认官方上位机已关闭、串口号正确、电机 ID 正确、机械限位安全。

推荐顺序：

1. `feedback_basic.py`  
   只读取反馈，不使能、不发目标位置。用于检查通信、接线、电机是否有返回。

2. `pp_basic.py`  
   PP 位置控制：设置速度/加速度限制，然后发送目标角度。适合确认库能驱动电机。

3. `motion_control_basic.py`  
   运控模式基础示例，使用反馈检查和保守的 `Kp/Kd`。确认 PP 稳定后再测试。

4. `csp_basic.py`  
   CSP 位置模式示例。上位机周期性发送小幅正弦位置点。

5. `speed_basic.py`  
   速度模式示例。适合连续旋转机构；有限角度关节上谨慎使用。

6. `current_basic.py`  
   电流模式示例。风险最高，只用很小电流短时间测试。


补充：

- `check_no_motion.py`  
  低风险恢复/检查脚本：清故障、读版本、停止。不使能、不发目标。

- `motion_return_zero.py`
  可扩展的多电机回原位初始化示例：调用 `return_motors_to_zero()`，用最近等价 raw 目标回到 wrapped zero。后续动作可以直接写在初始化函数后面。

注意：

- 速度模式、电流模式和 CSP 模式都提供了基础示例，但需要确认机械结构允许对应运动。
- 运控模式比 PP 模式风险更高，第一次测试请使用小角度、低 `Kp/Kd`、`torque_nm=0`。
- 这些示例都通过了 Python 语法检查；是否适合你的实机，需要按接线、限位、负载和电机 ID 逐步验证。
